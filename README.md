# USSD-BANK
A ussd bank that performs transactions

## Description of the Code

This code is a simple banking system program that allows a user to perform basic bank operations such as depositing money, withdrawing money, checking the balance, and exiting the program. It uses a menu-based interface so the user can choose an action. The program updates the account balance after each transaction and checks whether the user has enough funds before allowing a withdrawal. The **PIN for transactions is 4589**, and it is required for certain banking actions to be completed.
